# uzhavan-vazhikatti
🌾 Uzhavan Vazhikatti is a Tamil-language crop recommendation website designed to help Tamil Nadu farmers identify suitable crops based on their district, soil type, season, and irrigation facilities. It provides climate information, agricultural zone details, crop suitability scores, and recommendations using HTML, CSS, and JavaScript.
